常见问题

ATLAS 目前是完整上线的在线服务吗？

本网站包含可浏览的产品界面与部分本地演示交互。除页面明确说明外，不应将演示状态视为已连接真实账户、后台数据或生产 API。具体功能以实际部署和页面提示为准。

AI 对话内容会发送到哪里？

取决于你选择的模型和实际部署。AI 请求可能传送给相应模型服务商。提交敏感内容前请查看该服务商的处理地点、保存期限、训练用途及退出选项。详细说明见隐私政策的 AI 章节。

怎样管理本地保存的偏好？

部分外观偏好仅保存在当前浏览器。清除网站数据、切换浏览器或设备可能会移除这些偏好。页面上的本地设置不代表服务器账户资料已更改。

如何请求访问、更正或删除个人信息？

请通过隐私政策列出的联系邮箱提交请求，并说明涉及的功能。运营方可能需要核验身份后处理；若数据保存在第三方服务中，也可能需要直接向该服务商提出请求。

API 和开发者集成已经开放了吗？

本网站展示的 API 路径和代码目前仅用于说明 API 设计形式，不是可调用的线上端点。只有在正式发布开放说明、真实端点和认证方式后，才可据此进行集成。
